# Momentum V2

Initial static website concept for Momentum V2.

## Preview

Open `index.html` in a browser to view the landing page. The current version
uses pure HTML and CSS to render an animated blue phantom with a glowing aura
background.

## Notes

- No build step or dependencies are required.
- The CSS phantom is a placeholder that can be replaced with the final GIF,
  WebM, SVG, or Lottie asset when the exact artwork is available.
