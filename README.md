# momentumv2

Landing page for the new Momentum website, featuring the animated blue
phantom mascot with a glowing aura in the hero background.

## Running locally

No build step — it's plain HTML and CSS. Open `index.html` directly in a
browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.

## Files

- `index.html` — page structure (hero with phantom scene, preview section)
- `styles.css` — all styling and the phantom/aura/spark animations
